# أذكار اليوم

تطبيق للمصحف الشريف وأذكار اليوم وكتب الحديث والعقيدة، مع بوصلة للقبلة.

يعمل دون إنترنت بعد التثبيت.

ألوان فاتحة، أيقونة هندسية، شريط زجاج سائل يُضبط من الإعدادات، وأنيميشن عند الفتح والتنقل.
